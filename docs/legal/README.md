# 법무 문구 (결제/IAP 대응)

붙여넣기용 초안. **법적 최종 책임은 사업자에게 있으며 법무 검토 권장.**

## 파일 (어드민 *설정* 페이지 → 해당 언어 탭에 **전문 교체**)
- 약관:   `eula_ko.txt` / `eula_en.txt` / `eula_de.txt`
- 방침:   `privacy_ko.txt` / `privacy_en.txt` / `privacy_de.txt`

코드 시드(`server/db/database.js`)는 `ON CONFLICT DO NOTHING`이라
실서버에 자동 반영되지 않음 → 반드시 어드민에서 직접 갱신.

## 적용 전 확인할 값
- 사업장 주소: "경기도 고양시 덕양구 충경로 138, 303동 508호" — 사업자등록증과 대조
- 통신판매업 신고번호: "제2026-고양덕양구-0658호" — 등록증 표기와 글자 일치
- 시행일: 2026년 5월 15일 — 실제 적용일로 조정 가능

## 확인 위치
- 앱: 설정 > 이용약관 / 개인정보처리방침 (서버 config·접속 언어 기준 표시)
- 상점 고지: 골드 충전 화면 하단 "구매 전 안내"
- 어드민: 설정 페이지 (ko/en/de 탭에서 편집·저장)
- 검수: en/de는 기계 번역 초안 → 가능하면 원어민/법무 감수
